4

Первый сайт. Бесплатно, за вечер

Claude умеет делать артефакты: готовые страницы и мини-программы прямо в чате. Сайт это и есть такая страница. Опубликовал, получил ссылку, отправил.

4.1 Попроси сайт

В проекте Claude Mastery отправь:

Промпт 1 · сайт
Хочу свой первый сайт. Я не программист. Сделай его артефактом прямо здесь, одной страницей.

Сначала задай мне вопросы по одному, не списком:
- кто я и чем занимаюсь;
- для кого сайт и что человек должен сделать на нём (написать мне, купить, записаться);
- какой стиль нравится: цвета, настроение, пример сайта, если есть.

Потом сделай страницу: понятный заголовок, кто я, что предлагаю, 3 причины выбрать меня, кнопка связи. Сайт должен нормально выглядеть на телефоне. Тексты пиши простым языком, без воды.

В конце скажи, как опубликовать страницу и получить ссылку.

Ответь на его вопросы. Справа откроется панель с готовой страницей. Не нравится, пиши словами: «сделай фон тёмным», «кнопку больше», «убери второй блок».

4.2 Картинки для сайта из AI Creator

Сайт с заглушками вместо фото выглядит дёшево. Картинки делает мой второй ассистент, AI Creator: главный баннер, иконки, фон, аватарка. Он даёт промпт, ты генерируешь его в Syntx, это сайт, где собраны все нейросети для картинок.

Промпт для AI Creator · картинки для сайта

1. Главный баннер, горизонтальный 16:9.
2. Три иконки в одном стиле для блока «почему я».
3. Аватарка для блока «обо мне» [приложу своё фото, если нужно].
Дай промпты по одному: в какую нейросеть Syntx вставить, формат кадра, английский промпт и перевод одной строкой.

Готовые картинки перетащи в чат с Claude и напиши: «вставь эти картинки на сайт вместо заглушек».

4.4 Свой адрес вместо ссылки Claude. По желанию

Хочешь адрес вида imya.github.io? Это тоже бесплатно, через GitHub. Терминал не нужен.

  1. Скачай сайт файлом: попроси Claude «дай этот сайт одним файлом index.html» и скачай файл из ответа.
  2. Зарегистрируйся на github.com. Логин латиницей, он станет частью адреса.
  3. Сверху справа +, потом New repository. Название ровно твойлогин.github.io, доступ Public. Нажми Create repository.
  4. Нажми uploading an existing file или Add file → Upload files. Перетащи index.html и картинки. Внизу Commit changes.
  5. Через пару минут сайт откроется по адресу твойлогин.github.io. Не открылся: Settings → Pages, в Branch выбери main и Save.

7

Уровень 2: Claude Code

До этого Claude делал всё внутри чата. Claude Code работает прямо на твоём компьютере: создаёт файлы, запускает программы, сам проверяет, что получилось. Боты, серьёзные сайты, автоматизации делаются здесь.

7.1 Что нужно

  • Тариф Pro. Claude Code на бесплатном тарифе не работает. Pro стоит $20 в месяц. Российской картой его не оплатить, оплачивают зарубежной картой или через сервисы оплаты зарубежных подписок.
  • Приложение Claude для компьютера, Mac или Windows: claude.com/download. Терминал не нужен, всё в окне приложения.

7.2 Первый запуск

  1. Создай на компьютере папку для работы, например Мои проекты. Положи в неё всю распакованную папку Claude Mastery by NIK SHEN, с файлами и базой знаний.
  2. Открой приложение Claude. Сверху три вкладки: Chat, Cowork, Code. Нажми Code.
  3. Под полем ввода выбери: окружение Local, папка проекта Мои проекты.
  4. Режим разрешений для начала оставь, где Claude спрашивает перед каждым действием. Он покажет, что хочет сделать, а ты жмёшь «разрешить».

7.3 Ставим Claude Mastery в Claude Code

Claude Code не видит проекты с сайта. Зато он при каждом запуске сам читает файл CLAUDE.md из рабочей папки. Кладём туда «мозг» ассистента, и он работает в Claude Code. Руками ничего делать не надо, Claude Code сделает сам. Отправь:

Промпт 4 · ассистент в Claude Code
В этой папке лежит папка «Claude Mastery by NIK SHEN». Сделай так:
1. Создай в корне этой рабочей папки файл CLAUDE.md.
2. Перенеси в него весь текст из файла «Claude Mastery by NIK SHEN/04_инструкция-для-проекта.txt», всё, что ниже линии из трёх дефисов.
3. В конец CLAUDE.md добавь строку: «База знаний лежит в папке Claude Mastery by NIK SHEN/база-знаний/. Начинай с 00_INDEX.md.»
Ничего больше не меняй. Когда закончишь, покажи мне начало файла.
  1. Claude покажет, что хочет создать файл. Разреши.
  2. Начни новую сессию: кнопка новой сессии слева сверху, та же папка.
  3. Напиши Привет! Кто ты?
он представился как Claude Mastery от NIK SHEN. Ещё можно отправить команду /context: в списке Memory files будет CLAUDE.md.
Каждый новый проект (сайт, бот) создавай подпапкой внутри Мои проекты. Claude Code читает CLAUDE.md и из папок выше, так что ассистент будет с тобой в каждом проекте.

Бот, который отвечает людям, принимает заявки, записывает на услуги. Пишет его Claude Code, ты даёшь только токен и описание словами.

8.1 Получи токен у @BotFather

Токен это пароль, по которому программа управляет ботом. Его выдаёт официальный бот Telegram.

  1. Открой в Telegram @BotFather и нажми Start.
  2. Отправь /newbot.
  3. Напиши имя бота, его видят люди: «Помощник Анны».
  4. Напиши адрес бота латиницей, в конце обязательно bot: anna_help_bot.
  5. BotFather пришлёт токен: длинная строка из цифр и букв через двоеточие. Скопируй.
Токен никому не показывай и не отправляй в чаты. Кто знает токен, управляет ботом. Утёк: в BotFather отправь /revoke, получишь новый.

Два сценария, которые реально работают у новичка.

9.1 Задача по расписанию

На тарифе Pro Claude умеет выполнять задачи сам в назначенное время. Например, каждое утро собирать сводку, каждую пятницу готовить отчёт.

  1. В Claude напиши, что сделать и как часто. Можно начать с команды /schedule.
  2. Claude уточнит детали и покажет задачу: название, расписание, инструкцию. Проверь и нажми Schedule.
  3. Все задачи видны слева в разделе Scheduled.
Промпт 9 · по расписанию
Каждый будний день в 9:00 [что сделать: например, найди 5 свежих новостей про нейросети для дизайнеров и сделай короткую сводку по-русски, по 2 предложения на новость].
Если задаче нужны файлы с твоего компьютера, приложение Claude в это время должно быть открыто. Задачи, которым хватает интернета и подключённых сервисов, работают и при выключенном компьютере.

Сделай самым простым способом, который будет работать без моего компьютера. Объясни каждый шаг и проверь сам: отправь тестовую заявку.
